همگام‌سازی ابری
اطلاعاتت رو با یه دیتابیس Firebase رایگان بین گوشی و لپ‌تاپت همگام کن. راهنمای ساخت دیتابیس رایانش اینجا.
۱. برو به console.firebase.google.com و یه پروژه‌ی رایگان بساز.
۲. از منو Realtime Database رو بساز (حالت test mode کافیه).
۳. آدرس دیتابیس (چیزی شبیه https://xxx-default-rtdb.firebaseio.com) رو این‌جا وارد کن.
۴. یه «کد همگام‌سازی» دلخواه و نسبتاً پیچیده بساز و همون رو تو همه‌ی دستگاه‌هات وارد کن.
توجه: در حالت test mode هرکسی که کد رو بدونه به اون داده دسترسی داره؛ فقط برای همگام‌سازی شخصی خودت استفاده کن، نه داده‌ی حساس.
